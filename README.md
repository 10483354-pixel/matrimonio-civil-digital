# MATRIMONIO CIVIL DIGITAL — PRO ACTUALIZADO

Proyecto académico desarrollado con HTML5, CSS3 y JavaScript.

## Archivos
- `index.html`
- `style.css`
- `script.js`
- `portal.png`

## Características
- Panel institucional.
- Imagen principal `portal.png`.
- Nueva solicitud matrimonial.
- Contrayentes y testigos.
- Expediente digital simulado.
- Gestor de documentos.
- Apertura de documentos oficiales en nueva pestaña.
- Vista documental mediante modal/iframe cuando el portal lo permite.
- Carga de archivos locales como ficha de simulación.
- Checklist dinámico para Lima y Cajamarca.
- Casos de divorcio, viudez y contrayente extranjero.
- Seguimiento por código de expediente.
- Calendario de ceremonia.
- Información del flujo del trámite.
- Diseño responsive.
- Persistencia local mediante `localStorage`.

## Importante
Es una simulación académica. No constituye un sistema municipal real, no procesa pagos ni presenta expedientes ante una municipalidad y no debe utilizarse con datos personales reales.

Los requisitos, formatos, costos y enlaces pueden cambiar según la municipalidad y la fecha. Verificar siempre las fuentes oficiales vigentes.
